Iniciando estudos DOM

Selecionando os elementos dom

Posso selecionar os elementos DOM: por marca (tagname); por ID; por classe; por seletor (por CSS)

Existem alguns comandos que nós vamos utilizar

Por marca (tagname)

O comando é o getElementsByTagName

Como está no plural getElements... eu preciso dizer o número do elemento que eu quero ultilizar, lembrando que no JS, a contagem dos elementos começa do zero

Por ID

O comando é: getElementsById

Preciso atribuir um ID na tag que eu quero manipular

Por class

O comando é getElementsByClassName

Por seletor CSS

O comando é: querySelector

Se a tag que eu quero selecionar estiver com Id, eu uso hashashtag (#), mas, se estiver em uma classe, eu uso ponto (.)

Selecionando elementos por name

O comando é getElementsByName
